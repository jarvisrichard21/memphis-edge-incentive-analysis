# README.md — Analysis Outputs
This folder contains the CSV files generated from the SQL queries used to answer the project’s research questions. These outputs represent the analytical results produced in PostgreSQL and serve as the data sources for all supporting visuals in the project.

# What these files represent
• 	Final query results used to support the narrative analysis
• 	Clean, structured datasets ready for charting and mapping
• 	Direct links between SQL logic and visual insights
# How they are used
These CSVs feed into the charts, maps, and tables included in the insights section of the project, helping illustrate patterns in investment, job creation, and geographic distribution across EDGE incentive programs.
