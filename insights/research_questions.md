# README.md — Research Questions
This folder contains the core research questions that guide the analysis for the Memphis EDGE Incentive Program project. The  file outlines the key analytical themes and serves as the foundation for all SQL queries, outputs, and findings.
# Purpose of this section
• 	Define the central questions the project aims to answer
• 	Provide a clear analytical framework for the SQL and visualizations
• 	Ensure the findings directly connect back to the project’s objectives
These questions anchor the entire analysis and shape the narrative presented in the final findings.

# Guiding Questions
The analysis answers three core questions:

* How much investment has EDGE supported across Memphis, and how does it vary by program?
* How much did each program contribute to total jobs, which program contributed the most?
* How is EDGE investment distributed across Memphis ZIP codes or neighborhoods?
