# README.md — Visuals
This folder contains the charts, maps, and tables used to support the findings in the project’s analysis. All visuals are generated from the SQL output files and are included here as final presentation assets.

# Purpose of this folder
• 	Store exported Datawrapper charts, maps, and tables
• 	Provide visual references for the insights section
• 	Maintain a clear link between SQL outputs and the narrative analysis
These visuals help illustrate patterns in investment, job creation, and geographic distribution across EDGE incentive programs.
