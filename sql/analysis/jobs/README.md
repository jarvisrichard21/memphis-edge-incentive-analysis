# total_jobs_by_program.sql
Purpose
Calculates the total number of jobs associated with each EDGE incentive program (PILOT, TIF, Bonds, Loans, Other Projects). This provides a high‑level comparison of job impact across all program types.

# What the query does
• 	Aggregates job counts from each program table
• 	Standardizes the output into a single combined dataset
• 	Allows for cross‑program comparison of job creation and retention
• 	Supports summary tables and bar chart visualizations

# Use case
Useful for answering questions such as:
• 	“Which EDGE program supports the most jobs?”
• 	“How do PILOT jobs compare to TIF or Bond jobs?”
• 	“What is the overall employment impact of EDGE incentives?”

# jobs_by_project_type.sql
Purpose
Breaks down PILOT‑related jobs by project type (e.g., manufacturing, logistics, headquarters). This query highlights which types of PILOT projects generate the most employment.
# What the query does
• 	Groups PILOT projects by project type
• 	Sums total jobs for each category
• 	Produces a ranked list of job‑producing project types
• 	Supports visuals such as bar charts or category comparisons
# Use case
Ideal for understanding:
• 	which industries benefit most from PILOT incentives
• 	how job creation varies by project type
• 	where employment impact is concentrated within the PILOT program
