# Geography SQL Queries

## zipcode_project_counts.sql
Calculates the total number of EDGE-supported projects by ZIP code across all incentive programs.  
This query is used to identify geographic concentrations of investment activity.

## project_type_by_zipcode.sql
Summarizes PILOT-supported jobs by project type for each ZIP code and highlights which project types have the highest geographic concentration.  
Useful for understanding how specific industries or project categories cluster across Memphis ZIP codes.
