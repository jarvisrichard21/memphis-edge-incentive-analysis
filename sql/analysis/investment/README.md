# investment_by_pilot_project_type.sql
Purpose
Breaks down total capital investment within the PILOT program by project type. This query helps identify which types of PILOT projects (e.g., manufacturing, logistics, headquarters, mixed‑use) receive the largest share of investment.

#What the query does
• 	Groups PILOT projects by their project type
• 	Sums total capital investment for each category
• 	Produces a ranked list showing which project types dominate PILOT investment
• 	Supports visualizations such as bar charts or percentage breakdowns
# Use case
Useful for understanding how PILOT incentives are distributed across industries and which sectors benefit most from PILOT‑supported investment.

# total_investment_by_program.sql
Purpose
Calculates the total capital investment across all EDGE incentive programs (TIF, PILOT, Bonds, Loans, Other Projects). This provides a high‑level comparison of how investment is distributed across the different program types.
# What the query does
• 	Aggregates total investment from each EDGE program table
• 	Standardizes the output into a single combined dataset
• 	Allows for cross‑program comparison
• 	Supports visuals such as horizontal bar charts or summary tables
# Use case
Ideal for answering questions like:
• 	“Which EDGE program accounts for the most investment?”
• 	“How does PILOT investment compare to TIF or Bond programs?”
• 	“What is the overall scale of EDGE‑supported investment?”
